# 配置备份与升级到 Go 2.0

以下导入导出入口适用于 **1.6.1 开发版本和 Go 2.0 候选版本**。是否已包含在你安装的包中，以版本说明为准。

## 在 LuCI 导出和导入

打开 **服务 → 智慧深澜 → 进阶设置 → 配置备份**。

1. 点击「导出配置」，将 JSON 保存到自己的电脑。
2. 恢复时点击「选择备份文件」。校验成功后，页面显示校园账号、热点数量，以及版本转换说明。
3. 确认内容后点击「确认导入」。它替换现有插件配置，并关闭自动守护。
4. 检查账号、认证地址、网口与无线设备；确认后再启用自动守护。

备份含校园账号密码与热点密钥，请妥善保管，不要上传到 Issue、日志或公开仓库。预览只显示数量和说明。文件上限为 512 KiB；格式错误、账号引用无效或预览后配置已发生变化时，导入会被拒绝，需要重新预览。网络中断或导入超时时先刷新确认结果，不要连续重复导入。

备份包含插件设置、校园账号、热点和学校扩展配置。它不包含系统网络/UCI 配置、认证会话、日志、公钥信任库或自建学校预设目录。自建预设需单独备份。

1.x 有认证、切网或服务恢复保护任务时，先等待任务完成并返回校园网络再导入。Go 正在更新、执行互斥任务或无线向导尚未结束时，也可能拒绝修改配置。

## 从 1.6.1 转到 Go

先在 1.6.1 导出配置，再安装适合设备的 Go 包，最后在 Go 的进阶设置中导入该 JSON。Go 不在启动时扫描或自动改写旧配置文件。旧版原始 `config.json` 和 `config show` 输出不是新版备份格式，请使用「导出配置」生成版本化文件。

转换保留账号关联、密码、任意运营商后缀和明确的空后缀，以及逐账号认证参数。无线账号与有线账号只启用各自适用的字段；导入到另一台路由器后务必核对网口和 radio 名称。

Go 使用 `retry_cooldown_seconds` / `retry_max_cooldown_seconds` 对应的重试等待值。1.x 的开发模式和旧退避公式参数不再适用，预览会说明。1.x 没有每日预设更新时间，导入后采用 Go 默认的北京时间 09:00；可在进阶设置关闭或调整。Go 2.0 的备份保留自己的每日更新设置。

这是从 1.6.1 到 2.0 的显式导入。1.6.1 不接受 2.0 导出的备份；回退前保留原始 1.6.1 备份和对应安装包。

## 命令行

两版均提供：

```sh
srunnet config export /tmp/smart-srun-backup.json
srunnet config import /tmp/smart-srun-backup.json --check
srunnet config import /tmp/smart-srun-backup.json --expected-revision REVISION
```

将 `REVISION` 替换为预览返回的 `expected_revision`：1.6.1 使用配置摘要，Go 使用数字修订号。文件路径使用 `-` 时从标准输入读取或向标准输出导出；不要把含密码的输出粘贴到公共终端记录。导出到文件时使用 `0600` 权限，且不会覆盖已存在的文件。

Go 的命令通过本地守护进程执行，守护进程不可用时会报错。导入命令不会为了恢复备份而自动启动旧配置的认证流程。正常运行时可以关闭「自动守护」而保留配置服务。

## 文件位置

| 内容 | 1.x | Go 2.0 |
| --- | --- | --- |
| 主配置 | `/usr/lib/smart_srun/config.json` | `/etc/smart-srun/config.json` |
| 自建学校预设 | `/usr/lib/smart_srun/user_presets.json` | `/etc/smart-srun/user-presets.json` |

两版文件结构不同，勿直接跨版本覆盖这些路径。自建预设使用各自的编辑或导入入口处理，主配置导入不会自动迁移它们。
