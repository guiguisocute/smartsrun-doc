# 运行状态、定时与日志

## 状态卡

默认展示在线状态、当前网络与账号。展开 **连接详情** 后，按网络连接、无线连接和运行信息查看接口、IP、实际 AP、信号、检测间隔等。展开状态在刷新时保留；有线隐藏无线分组，错误和待执行操作直接显示。

“在线判定方式”有三种：

| 配置值 | 判断依据 | 限制 |
| --- | --- | --- |
| `internet` | 互联网探测 | 默认方式，结果与探测目标和当前线路有关 |
| `portal` | 认证网关可达 | 网关可达不代表外网可用 |
| `ssid` | SSID 匹配 | 无法仅凭 SSID 确认认证或互联网连通性 |

运行状态中的 `connectivity_level=portal` 表示网关可达而互联网探测失败，不是对“门户拦截”或某个认证错误的最终诊断。

## 守护、手动操作与定时切网

**启用**控制后台自动认证、重连和定时处理；手动登录、登出始终可用。Go 2.0 手动登出会暂停该账号的自动认证，即使网关未确认退出也不会立即自动重登；手动登录成功可恢复。暂停跨服务重启保留，保存新配置后重新按配置执行。网关会话是否退出以动作结果为准。旧 1.x 用户需停用自动认证以保持登出。

定时时段使用北京时间 `HH:MM`，可跨午夜。进入下线时段时暂停维护；是否主动登出由“进入下线时段时强制下线”控制。多 WAN 下会纳入托管账号与当前活动有线会话，去重登出，并仅重试失败项。

开启“登出时自动切换热点上网”且已配置热点时，可在下线时段切换网络；时段结束后恢复校园网维护。“热点切换失败时自动回切校园网”控制切换失败后的回退。Go 的手动切网保存当前选择，不改写全局自动认证开关；时段内手动选择热点仍会在时段结束后按计划回到校园网，相关边界见[认证说明](/guide/authentication#手动登出与热点切换)。

## 日志

LuCI **日志**页提供日志通道及等级过滤；CLI 使用 `srunnet log` 或 `srunnet log -n 80`。Go 默认插件日志在 `/tmp/smart-srun/plugin.log`，达到容量上限后截留最近记录；路径和存储边界见[配置参考](/reference/configuration#go-存储与字段契约)。日志位于内存文件系统，设备重启会清除。

等级从详细到精简为 `ALL / DEBUG / INFO / WARN / ERROR`。共享日志或截图前检查账号、SSID、IP、凭据和会话信息；不要公开完整配置或原始认证响应。
