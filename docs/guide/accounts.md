# 账号、无线与多 WAN

## 校园网账号与热点配置

校园网账号保存在 `campus_accounts`，热点保存在 `hotspot_profiles`。默认项与当前活动项分别记录；新增账号后应检查默认项。账号可独立填写认证地址、`AC_ID`、接入方式、后缀及高级登录参数。

有线账号使用 `wired_iface` 指定 OpenWrt 逻辑接口或 Linux 设备，如 `wan`、`wan.v2`。读取旧配置时兼容 `network_interface`；编辑保存统一使用 `wired_iface`。

热点配置表示路由器要连接的个人热点，不是创建供其他设备连接的 AP。可保存多个热点，并选择默认热点用于自动切换。

## 校园 Wi-Fi 的 AP 选择

无线校园账号的 **进阶设置 → AP 选择** 提供：

| 策略 | 行为 |
| --- | --- |
| 系统自动 `auto` | 由无线系统选择同 SSID 接入点 |
| 连接时信号优先 `strongest` | 连接或重连时扫描，在同 SSID、同 radio、信道兼容的接入点中按信号最多尝试 3 个 |
| 固定 BSSID `fixed` | 只连接指定 BSSID；失败不回退到其他 AP |

信号优先仅在关联或获取 IPv4 失败时尝试下一 AP；认证失败不触发 AP 轮换，在线期间也不主动扫描漫游。扫描不可用时交由系统自动选择。旧账号已填写 BSSID 且没有策略字段时，按固定策略兼容；切回自动策略后，记住的 BSSID 不参与选点。

状态卡中的 AP、无线接口、信号和信道来自当前连接，未知值显示“未知”，不会将配置中的 BSSID 冒充实际连接。信号以 dBm 表示，通常越接近 0 越强。

## 多 WAN 并行认证

1. 先在 OpenWrt 中配置每条有线出口，使其能获得 IPv4。
2. 为每条线路添加校园网账号，指定该线路的 `wired_iface`、认证参数及凭据。
3. 勾选账号的 **参与并行守护**（`auth_enabled=1`）。
4. 开启全局 **多 WAN 并行认证**（`multi_wan_enabled=1`），并启用后台自动认证。

多 WAN 开启时，只维护已勾选的有线账号；勾选集合为空不会在白天自动回退为认证默认有线账号。该功能不自动创建出口、路由表或负载均衡规则。

每条线路独立解析设备与源 IPv4，认证、探测和在线查询保持同一绑定。严格绑定失败、缺少地址或客户端无法保证绑定时，该线路请求会停止，不能借用其他 WAN 的连通性。既有单线配置保留兼容行为。
